# Sistema visual UI UX Pro Max

## Dirección aplicada

Se inicializó UI UX Pro Max para Codex en la carpeta .agents/skills y se generó la guía persistente en design-system/epsel-sistema-de-papeletas/MASTER.md.

El portal adopta una dirección de minimalismo institucional: superficies claras, grilla ordenada, jerarquía tipográfica fuerte, sombras cortas y movimiento sutil. Se conserva la identidad visual EPSEL con azul profundo y turquesa como color de acción.

## Cambios globales

- Fondo con profundidad ligera y contraste alto para el contenido.
- Navegación lateral, tarjetas, tabla y encabezados con bordes y elevación consistentes.
- Estados hover, foco y pulsación más claros en enlaces, botones y tarjetas.
- Campos de formulario más legibles y foco turquesa visible.
- Adaptación móvil para que los encabezados de tarjeta y sus acciones se apilen sin superponerse.
- Respeto por prefers-reduced-motion para eliminar desplazamientos visuales cuando el usuario lo solicita.

## Criterios de calidad

Se mantienen iconos SVG, controles con etiqueta accesible, contraste de lectura, diseño responsive y una sola acción principal visual por contexto. Las animaciones usan transform y opacidad, evitando cambios de dimensiones que provoquen saltos de interfaz.
