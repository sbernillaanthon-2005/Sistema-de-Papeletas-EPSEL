# Rediseño del dashboard de Administración

## Propósito

El dashboard administrativo se reorganizó como un panel de operación diaria. Mantiene las mismas rutas, filtros y acciones, pero prioriza lo que un administrador necesita decidir: disponibilidad de cuentas, papeletas que requieren atención, distribución del flujo y control de accesos.

## Composición

- Hero administrativo con el estado de cuentas activas, cantidad de papeletas pendientes y accesos directos para revisar papeletas o registrar una cuenta.
- Indicadores KPI con una marca inferior por categoría para distinguir personal, accesos, responsables y áreas.
- Bloque de seguimiento de firmas destacado como tarea operativa prioritaria.
- Cabecera de analítica que explica que las filas permiten profundizar mediante filtros.
- Directorio presentado como área de gobierno, con resumen de cuentas activas y controles de búsqueda agrupados.

## Diseño y accesibilidad

Se usó la guía de UI UX Pro Max para la variante admin-dashboard: jerarquía de operaciones, profundidad moderada, acciones principales visibles y composición responsive. El diseño está disponible también en modo oscuro y las animaciones siguen respetando la preferencia de movimiento reducido.
