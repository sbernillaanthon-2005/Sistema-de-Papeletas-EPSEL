# Dashboard administrativo como centro de control

## Objetivo

Aplicar la referencia visual entregada al panel **Usuarios y accesos**, priorizando el resumen operativo y el directorio.

## Cambios

- Se agrupó el título del centro de control con accesos rápidos para crear usuarios, abrir papeletas, consultar auditoría y gestionar respaldos.
- Se compactaron las cuatro métricas, el panel de recordatorios, los tres indicadores operativos y el directorio de personal.
- Se mantuvieron las rutas, filtros, acciones de usuario y configuración del intervalo de recordatorios.
- Se agregaron ajustes para pantallas angostas y tema oscuro.
